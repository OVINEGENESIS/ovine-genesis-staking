# Ovine Genesis Staking — V1

Static demo UI for Ovine Genesis staking.

## Deploy with Cloudflare Workers

Deploy command:

```bash
npx wrangler deploy
```

No build command is required.

- Demo wallet button
- Demo staking interactions
- Demo points calculation
- Demo leaderboard
